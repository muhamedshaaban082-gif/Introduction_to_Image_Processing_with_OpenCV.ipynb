# Introduction to Image Processing with OpenCV

## Overview
This project provides a practical introduction to Image Processing and Computer Vision using Python and OpenCV.

## Topics Covered
- Image Loading and Visualization
- Image Color Space Conversion (BGR to RGB)
- Gaussian Blur
- Region of Interest (ROI)
- Canny Edge Detection
- Image Rotation using Affine Transformation
- DICOM Image Conversion using Pydicom

## Libraries Used
- OpenCV
- NumPy
- Matplotlib
- Pillow
- Pydicom

## Environment
Google Colab / Jupyter Notebook

## Project File
`Introduction_to_Image_Processing_with_OpenCV.ipynb`

## Purpose
The goal of this notebook is to understand fundamental image processing techniques and gain practical experience with Python libraries used in Computer Vision.
